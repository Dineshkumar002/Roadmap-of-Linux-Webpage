Quick Cheat Sheet

The most essential Linux commands at a glance

Navigation

  • pwd — Print working directory
  • ls -la — List all files with details
  • cd /path — Change directory
  • cd .. — Go up one level
  • cd ~ — Go to home directory

Files

  • touch file — Create empty file
  • cp src dst — Copy file
  • mv src dst — Move / rename
  • rm file — Remove file
  • rm -rf dir — Remove directory

Text

  • cat file — Print file content
  • grep "word" file — Search in file
  • head -n 10 — First 10 lines
  • tail -n 10 — Last 10 lines
  • wc -l file — Count lines

Permissions

  • chmod 755 file — Set permissions
  • chown user file — Change owner
  • sudo command — Run as root
  • whoami — Current user
  • id — User & group IDs

Processes

  • ps aux — List processes
  • top — Live process viewer
  • kill PID — Kill process
  • jobs — List bg jobs
  • bg / fg — Background/foreground

Network

  • ping host — Ping a host
  • curl url — HTTP request
  • wget url — Download file
  • ssh user@host — SSH connect
  • scp file user@host — Copy over SSH
