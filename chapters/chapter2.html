The Terminal & Shell

Open your first terminal, understand what a shell is, and run your very first Linux commands.

What is the Terminal?

The terminal (also called the console or command line) is a text-based interface where you type commands and receive text output. It gives you direct, powerful control over your system.

The shell is the program that interprets your commands. The most common shell on Linux is Bash (Bourne Again SHell). Other shells include zsh, fish, and sh.

Opening the Terminal

On Ubuntu desktop: press Ctrl + Alt + T or search for "Terminal" in the app launcher.

Once open, you'll see the prompt — a line waiting for your input:

username@hostname:~$

The ~ means you're in your home directory. The $ means you're a regular user (if it were #, you'd be root/superuser).

Your First Commands

echo — Print text

$echo "Hello, Linux!" Hello, Linux!

date — Current date and time

$date Mon Jun 8 10:30:00 UTC 2026

whoami — Your username

$whoami ubuntu

uname -a — System information

$uname -a Linux mypc 5.15.0 #1 SMP x86_64 GNU/Linux

clear — Clear the screen

$clear

Or use the keyboard shortcut Ctrl + L.

Command Structure

Linux commands follow this pattern:

command [options] [arguments]
PartExampleMeaning
commandlsThe program to run
option (short)-lModify behavior (single dash)
option (long)--allSame but spelled out (double dash)
argument/homeWhat to operate on

Example: ls -la /home = run ls, with options -l (long format) and -a (all files), on the /home directory.

Getting Help

man — Manual pages

$man ls # Opens the full manual for the ls command

Press q to quit the manual. Use arrow keys or Page Up/Down to scroll.

--help flag

$ls --help
