File System Navigation

Understand the Linux directory structure and navigate confidently using pwd, ls, and cd.

The Linux File System Tree

Linux uses a single directory tree starting at / (called "root"). Everything — files, devices, processes — lives somewhere in this tree.

/
├── bin/       # Essential user commands (ls, cp, mv...)
├── boot/      # Boot loader files, kernel
├── dev/       # Device files
├── etc/       # System config files
├── home/      # User home directories (/home/alice)
├── lib/       # Shared libraries
├── media/     # Mounted removable media (USB, CD)
├── mnt/       # Temporary mount points
├── opt/       # Optional software
├── proc/      # Virtual filesystem (running processes)
├── root/      # Home of the root user
├── sbin/      # System administration commands
├── tmp/       # Temporary files (cleared on reboot)
├── usr/       # User programs, libraries, docs
└── var/       # Variable data (logs, databases)

pwd — Where Am I?

$pwd /home/alice

ls — List Directory Contents

$ls Desktop Documents Downloads Music Pictures
$ls -l drwxr-xr-x 2 alice alice 4096 Jun 8 10:00 Desktop -rw-r--r-- 1 alice alice 1234 Jun 7 09:15 notes.txt
$ls -la # Shows hidden files too (those starting with .)
OptionMeaning
-lLong format (permissions, size, date)
-aShow all files including hidden
-hHuman-readable file sizes (KB, MB)
-tSort by modification time
-rReverse sort order

cd — Change Directory

$cd /etc # Go to /etc
$cd .. # Go up one level
$cd ~ # Go to your home directory
$cd - # Go to previous directory

Absolute vs Relative Paths

Absolute path starts from root /: always works no matter where you are.

/home/alice/Documents/notes.txt

Relative path starts from your current location:

Documents/notes.txt   # if you're in /home/alice
../alice/Documents     # using .. to go up first
💡 Tip: Use Tab completion when typing paths. Type the first few letters and press Tab — Linux fills in the rest!
