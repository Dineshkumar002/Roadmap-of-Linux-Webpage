Files & Directories

Create, copy, move, rename, and delete files and directories like a pro.

Creating Files

touch — Create an empty file

$touch myfile.txt # Creates empty myfile.txt

mkdir — Create directories

$mkdir projects # Creates a projects/ directory
$mkdir -p projects/linux/scripts # Creates nested directories in one command

Copying Files

$cp file.txt backup.txt # Copy file.txt to backup.txt
$cp file.txt /tmp/ # Copy to /tmp directory
$cp -r projects/ projects_backup/ # Copy entire directory recursively

Moving and Renaming

mv both moves AND renames files (same command):

$mv old.txt new.txt # Rename old.txt to new.txt
$mv file.txt /home/alice/Documents/ # Move file to Documents folder

Deleting Files

$rm file.txt # Delete a file
$rm -r projects/ # Delete directory and all contents
$rmdir empty_folder/ # Delete empty directory only
⚠️ Warning: Linux has no Recycle Bin! rm permanently deletes files. Always double-check before running rm -rf.

Wildcards

Wildcards let you match multiple files at once:

WildcardMatchesExample
*Any charactersrm *.txt deletes all .txt files
?One characterls file?.txt matches file1.txt, file2.txt
[abc]One of a, b, or cls [abc]* starts with a, b, or c
