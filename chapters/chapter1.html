Introduction to Linux

Learn what Linux is, why it matters, and how to set up your first Linux environment.

What is Linux?

Linux is a free, open-source operating system kernel created by Linus Torvalds in 1991. Unlike Windows or macOS, Linux is built on the philosophy that software should be free to use, study, modify, and distribute.

Today, Linux powers most of the internet's servers, all Android devices, supercomputers, embedded systems, and millions of desktop machines. Learning Linux gives you powerful tools used by developers, sysadmins, and engineers worldwide.

💡 Fun Fact: Over 96% of the world's top 1 million web servers run Linux. Most cloud platforms (AWS, Google Cloud, Azure) are built on Linux.

Linux Distributions

Linux comes in many "distributions" (distros) — packaged versions of the Linux kernel plus software. Each distro is tuned for different needs:

For learning, Ubuntu is strongly recommended — it has the best documentation, widest software support, and a friendly community.

How to Get Linux

Option 1: Virtual Machine (Recommended for Beginners)

Install a virtual machine manager like VirtualBox (free) or VMware, then download an Ubuntu ISO and create a VM. This lets you run Linux inside your existing Windows or macOS system without any risk.

Option 2: WSL2 on Windows

Windows Subsystem for Linux 2 lets you run a full Linux terminal directly in Windows 10/11:

wsl --install

This installs Ubuntu by default. Open the Start menu and search "Ubuntu" to launch it.

Option 3: Dual Boot

Install Linux alongside your current OS, choosing which to boot when your computer starts. Best performance, but requires partitioning your disk.

Option 4: Online Terminals

Try Linux right in your browser with no installation needed at replit.com, bellard.org/jslinux, or use a cloud VM from any provider.

The Linux Philosophy

Linux follows the Unix philosophy:

  • Do one thing and do it well
  • Everything is a file
  • Small tools that chain together
  • Text is the universal interface

This means instead of one giant app, Linux gives you dozens of small, powerful tools you combine to accomplish complex tasks. It's this philosophy that makes the command line so powerful.
